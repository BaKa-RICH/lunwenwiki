# Citation And Evidence Policy

Use this policy for multi-source synthesis, idea surveys, HYP argumentation,
EXP reports, and DEC records.

## Evidence Labels

- `EXTRACTED`: directly stated by source material.
- `INFERRED`: inferred from multiple local sources.
- `AMBIGUOUS`: source material is unclear or conflicting.
- `UNVERIFIED`: not yet supported by local material.

## Multi-Source Coverage

When a report claims to summarize a set of sources, include a source set or
coverage note. Separate:

- included
- skipped unreadable
- excluded wrong scope
- uncertain needs review

Do not list sources that are not used as evidence.

## Conflict Handling

When new evidence conflicts with existing conclusions, record:

- old claim
- new evidence
- conflict type: `empirical / methodological / theoretical`
- proposed handling: `keep-for-review / update-old-claim / create-decision`

## Experiment And Decision Claims

EXP reports and DEC records must distinguish:

- support
- weakening evidence
- anomalies or failures
- unknowns

Do not write partial support as full success. Do not write `weakens` as
`supported`.

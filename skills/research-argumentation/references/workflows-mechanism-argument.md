# Mechanism Argument Workflow

Use this workflow to make an idea more than module stitching.

## Steps

1. State the concrete problem.
2. Identify the prior assumption or bottleneck being challenged.
3. Identify the mechanism change introduced by the idea.
4. Explain why this mechanism should affect the target metrics or behavior.
5. State the observable prediction.
6. State the strongest failure condition.

## Output

```text
Problem:
Prior assumption:
Mechanism change:
Why it may work:
Observable prediction:
Failure condition:
```

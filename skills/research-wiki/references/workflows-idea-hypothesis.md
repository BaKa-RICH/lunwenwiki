# Idea And Hypothesis Workflow

Use this workflow for idea generation, candidate review, and candidate
promotion.

## Candidate Generation

1. Read current synthesis, field map, shared assumptions, gaps, comparisons,
   and relevant paper cards.
2. Create an idea batch only when the user asks for a write workflow.
3. Each candidate must include:
   - evidence
   - novelty or stitching point
   - why it may work
   - strongest objection
   - minimum validation experiment
4. Do not create HYP cards in this step.

## Candidate Discussion

Discuss the selected candidate before promotion. Clarify:

- the actual problem
- whether it is more than module stitching
- closest prior work
- strongest objection
- minimum validation

Use `research-argumentation` when the mechanism or objection needs tightening.

## Promotion

Promotion requires explicit user confirmation. Then:

1. Create or update `wiki/hypotheses/HYP-xxxx.md`.
2. Update the origin candidate batch.
3. Update `wiki/hypotheses/index.md`, `index.md`, and `log.md`.
